Sin ser un random ni el jesucristo del sistema queremos tener pernmisos de administrador pero limitados
- root y superusuario: jesucristo (hace todo)
- usuario random: no puede hacer nada fuera de su home

Archivo /etc/sudoers (NO editar a mano)
sudoers: tiene/almacena los permisos de superusuarios y grupos. (Què pueden hacer y qué no)
cuando se ve el: root ALL=(ALL) ALL
- El primer ALL es Host: puede trabajar desde cualquier equipo.
- El segundo ALL es por qué usuarios puede usar el su (loguearse por).
- El tercer ALL son los comandos que puede usar como tal.
(Los grupos se ven como %group)
Ejemplo: pepe Almalinux=(root) [Lista de comandos].

Cada Comando en linux es un programa.
which "comando": muestra donde se aloja el comando/ejecutable.
Ejemplo: which dnf, which ls, etc.
